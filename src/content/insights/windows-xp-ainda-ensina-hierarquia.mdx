Vinte e cinco anos depois, as janelas do Windows XP continuam fáceis de ler. Não por nostalgia: a interface resolvia a ordem de leitura com recursos que o design "limpo" jogou fora.

## Botão que parece botão

No XP, tudo que era clicável tinha volume: borda, luz em cima, sombra embaixo. O olho sabia o que apertar antes de ler o rótulo. O neobrutalismo recupera isso de outro jeito, com borda sólida e sombra dura que **afunda** quando você aperta. O gesto é físico, como um botão de fliperama.

## Barra de título é âncora

Cada janela começava com uma faixa colorida e um nome. Em um layout editorial, a mesma ideia vira um cabeçalho de cartão com cor própria: você reconhece o tipo de conteúdo antes de ler a primeira linha.

## O que levar para o próximo projeto

- Dê a cada nível da hierarquia **um** sinal visual forte, não três fracos.
- Faça os elementos interativos parecerem interativos, mesmo parados.
- Use cor para agrupar, não para enfeitar.

> interface boa é a que você entende de longe.
